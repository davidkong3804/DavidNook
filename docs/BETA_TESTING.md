# DavidNook Beta 試用說明（給同學）

DavidNook 是一個完全在本機執行的 Mac 瀏海工具：收合時是瀏海、滑鼠移上去會展開，裡面有**動態歌詞**、**播放控制**和**剪貼簿歷史**。
沒有帳號、沒有雲端同步、沒有任何追蹤；唯一的對外連線是 `lrclib.net`（只送歌名、歌手、長度來找歌詞）。

> 這是 **beta**：作者只在一台 Mac（Apple Silicon、macOS 27）上測過。你的回報就是這次試用最重要的東西。

## 你需要什麼

- **Apple Silicon（M1 以上）的 Mac**。這個版本只有 arm64，**Intel Mac 打不開**。
- macOS 14 以上（專案設定的最低版本）。作者只在 macOS 27 驗證過，其他版本是「應該可以」，不保證。
- 不需要開發者帳號、不需要 Xcode、不需要輸入任何密碼。

## 安裝（約 2 分鐘）

1. 下載作者給你的 `DavidNook-0.1.0-beta-arm64.zip`，雙擊解壓縮，會得到 `DavidNook.app`。
2. 把 `DavidNook.app` 拖到「應用程式」或任何你喜歡的資料夾（不要直接在「下載項目」裡執行）。
3. **第一次開啟會被 macOS 擋下**（因為這個 App 沒有向 Apple 付費公證，只有本機簽章，這是正常的）。處理方式擇一：
   - **方式 A（建議）**：雙擊開啟 → 看到被擋的視窗後按「完成」→ 打開「系統設定 → 隱私權與安全性」，往下找到「已阻擋『DavidNook』…」→ 按「**仍要打開**」→ 再確認一次。之後就不會再問。
   - **方式 B（終端機）**：只對這一個 App 移除下載標記：

     ```sh
     xattr -dr com.apple.quarantine /Applications/DavidNook.app
     ```

     （路徑請換成你放的位置。這個指令只是移除這個 App 的「從網路下載」標記，不會改任何系統設定。）
4. 開啟後會跳出一個說明視窗，看完按下一步即可。**這個視窗不會主動跳系統權限提示。**
5. 要確認檔案沒被改過，可以比對 SHA-256（見文末，作者會附上目前版本的值）：

   ```sh
   shasum -a 256 ~/Downloads/DavidNook-0.1.0-beta-arm64.zip
   ```

## 權限會在什麼時候被問

| 權限 | 為什麼 | 什麼時候 |
| --- | --- | --- |
| 自動化：「音樂」App | 讀取 Apple Music 的播放狀態（備援與控制） | 第一次實際需要時，macOS 會問，按「好」 |
| 從其他 App 貼上（macOS 15.4+） | 剪貼簿歷史要讀你複製的內容 | 第一次複製東西後；不想給就到設定關掉「記錄剪貼簿歷史」 |

不會要求「輔助使用」，除非你自己去開「點選後自動貼上」（實驗功能、預設關）。

## 怎麼用

- **展開／收合**：滑鼠移到螢幕最上方中央，停一下就展開；移開收合。也可以點一下展開。
- **歌詞**：用 Apple Music 或瀏覽器（例如 YouTube）播歌，歌詞會自動出現並跟著唱。簡體來源的中文歌詞會自動轉成繁體。
- **歌詞對不上**：不同版本的歌時間軸會不同。歌詞面板右下角有「對時」鈕：**聽到哪一句正在唱，就點那一句歌詞**，會自動對齊並記住這首歌；也可以用「歌詞太晚／太早」微調。
- **播放控制**：展開後有上一首／暫停／下一首。
- **剪貼簿**：展開後切到剪貼簿分頁。點一下某一列＝複製回剪貼簿；滑鼠移到列上可釘選、刪除；上方可搜尋；有「暫停記錄」。
- **設定**：選單列的 DavidNook 圖示 → 設定，可以調展開寬度與高度、動畫、是否開機啟動等。

## 隱私

- 所有資料只存在你的 Mac 上，沒有任何遙測。**不會**記錄密碼管理員標記為機密的內容（`ConcealedType` 等）。
- 剪貼簿歷史存在本機資料夾，可在設定裡「清除全部」；解除安裝時一併刪除（見下）。

## 回報問題

請直接傳給作者，**越具體越好**，但**不要貼完整歌詞，也不要貼你的剪貼簿內容**：

1. 你的 Mac 型號、macOS 版本。
2. 發生什麼事（例如「播周杰倫的 XXX，歌詞慢了約 2 秒」）、你期待什麼。
3. 歌曲在哪裡播放（Apple Music／YouTube 用哪個瀏覽器）、影片標題。
4. 如果 App 閃退：到「系統設定 → 隱私權與安全性 → 分析與改進 → 分析資料」找最新的 `DavidNook-…` 檔案傳給作者（內容是程式當機時的呼叫堆疊，不含你的資料）。

## 已知限制

- 只有 arm64（Apple Silicon）；Intel 未支援。
- 作者只有一台沒有實體瀏海的桌機可測；**有瀏海的 MacBook 上的位置與觀感是未驗證的**，請特別回報。
- 歌詞只來自 LRCLIB；沒收錄的歌會顯示沒有歌詞。MV 影片因為有前奏，歌詞常會整體偏早，需要用「對時」。
- 因為是本機簽章，**每次換新版本**，macOS 可能要你重新授權一次。

## 解除安裝

1. 結束 DavidNook（選單列圖示 → 結束），把 `DavidNook.app` 丟到垃圾桶。
2. 想連資料一起刪：刪除 `~/Library/Containers/io.github.davidkong3804.DavidNook`。
