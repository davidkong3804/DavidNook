# DavidNook 歌詞簡轉繁覆寫表
#
# 格式：簡體詞=繁體詞（每行一條；# 開頭為註解；空行忽略）
#
# 規則：
#  1. 簡體歌詞轉換時，先套用本表，再交給 OpenCC。掃描由左到右、同一位置「最長匹配優先」；
#     命中的片段直接輸出「繁體詞」，不會再交給 OpenCC（所以值等於鍵的條目＝「保護條目」，
#     用來擋住 OpenCC 會轉錯的字）。原生繁體歌詞（.variantsOnly）不使用本表。
#  2. 值必須是台灣標準繁體字形（裡、著、麼…），不得含簡體專有字；測試會檢查。
#  3. 只放兩類條目：(a) OpenCC 1.1.2 字典會轉錯的詞；(b) OpenCC 斷詞陷阱的防護
#     （例如「不断发展」會被切成「断发」→「不斷髮展」）。OpenCC 本來就轉對的詞不要重複放。
#  4. 新增條目請同時補測試（LyricsChineseConverterTests / LyricsOverridesTests）。
#  5. 風格決定（已採納）：簡體來源常見詞保留「台」「了解」（見檔尾「風格決定」段，以保護條目實作）。
#     刻意不處理：悽／溼／嘆／蒐／昇／週 等 OpenCC 異體選擇；污→汙；上傳檔把「只」寫成「隻」的錯誤。

# 「注定」：OpenCC 轉成「註定」（錯）；「注」在注意／注視／注射都是「注」，「註」只用於註解、註冊、註腳。

# 戲劇的量詞「齣」（一齣好戲、一齣悲劇）；OpenCC 只處理「一出戏」，其餘保留「出」。
