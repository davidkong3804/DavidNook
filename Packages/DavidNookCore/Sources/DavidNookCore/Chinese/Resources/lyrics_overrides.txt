# DavidNook 歌詞簡轉繁覆寫表
#
# 格式：簡體詞=繁體詞（每行一條；# 開頭為註解；空行忽略）
#
# 規則：
#  1. 簡體歌詞轉換時，先套用本表，再交給 OpenCC。掃描由左到右、同一位置「最長匹配優先」；
#     命中的片段直接輸出「繁體詞」，不會再交給 OpenCC（所以值等於鍵的條目＝「保護條目」，
#     用來擋住 OpenCC 會轉錯的字）。原生繁體歌詞（.variantsOnly）不使用本表。
#  2. 值必須是台灣標準繁體字形（裡、著、麼…），不得含簡體專有字；測試會檢查。
#  3. 只放兩類條目：(a) OpenCC 1.1.2 字典會轉錯的詞；(b) OpenCC 斷詞陷阱的防護
#     （例如「不断发展」會被切成「断发」→「不斷髮展」）。OpenCC 本來就轉對的詞不要重複放。
#  4. 新增條目請同時補測試（LyricsChineseConverterTests / LyricsOverridesTests）。
#  5. 刻意不處理（風格問題，待使用者回饋）：台→臺、了解→瞭解。

# ── 髮／發 ─────────────────────────────────────────────
# OpenCC 會把這些詞裡的「发」轉成「發」，但意思是頭髮。

发端=髮端
发丝=髮絲
发线=髮線
发尖=髮尖
发鬟=髮鬟
青丝白发=青絲白髮
白发=白髮
头发=頭髮

# 防護：上面的「髮」詞或 OpenCC 的「断发」「长发」會吃掉後面詞的「发」。

成长发=成長發
增长发=增長發

# ── 乾／幹／干 ────────────────────────────────────────
# OpenCC 會把「没干净」「才干净」切成「没幹」「才幹」+「淨」。

# ── 里／裡／裏 ────────────────────────────────────────
# OpenCC 把「海里」當成長度單位（海浬）；歌詞裡幾乎都是「在海裡」。
海里=海裡
# 疊詞成語：OpenCC 保留「里」，台灣寫「裡」。
糊里糊涂=糊裡糊塗
傻里傻气=傻裡傻氣
怪里怪气=怪裡怪氣
慌里慌张=慌裡慌張
妖里妖气=妖裡妖氣
邋里邋遢=邋裡邋遢

# ── 后／後／后 ────────────────────────────────────────

# ── 征／徵 ────────────────────────────────────────────
# OpenCC 把「征人」「征鸿」轉成「徵人」「徵鴻」；古典意象的征人、征鴻用「征」。
征人=征人
征鸿=征鴻
